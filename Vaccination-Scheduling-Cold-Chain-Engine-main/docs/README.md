Vaccination Scheduling and Cold-Chain Engine

Project Information

- Team ID: T113
- Problem Statement ID: PS-065
- Programming Language: Python

Project Description

The Vaccination Scheduling and Cold-Chain Engine is a Python-based project designed to support beneficiary registration, vaccination eligibility, dose tracking, appointment scheduling, vaccine inventory management, cold-chain monitoring, AEFI recording, and report generation.

Main Modules

1. Beneficiary Management
2. Dose Management
3. Vaccination Scheduling
4. Inventory Management
5. Cold-Chain Monitoring
6. AEFI Management
7. Report Generation

Technologies Used

- Python
- VS Code
- Python testing framework

Project Structure

- "src/" – Application source code
- "tests/" – Test cases
- "docs/" – Project documentation
- "data/" – Project data

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python src/main.py

Testing

Run the test suite using:

python -m pytest -q

Expected Outcome

A modular application that supports vaccination scheduling and cold-chain management operations.
